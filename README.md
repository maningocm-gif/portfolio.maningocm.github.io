# Chariza Mae Maningo — Portfolio 2.0

A static GitHub Pages portfolio redesign focused on:

- Mechanical Engineering
- Project & Documentation Support
- Administrative / Virtual Assistance
- Data & Excel
- Remote opportunities

## Uploading to GitHub

1. Open the repository:
   `https://github.com/maningocm-gif/portfolio.maningocm.github.io`
2. Replace the existing `index.html`, `styles.css`, and `script.js` with the files in this package.
3. Upload the `assets/` folder.
4. Before publishing, replace:
   - `assets/resume.pdf` with your latest résumé.
5. Add your real LinkedIn URL when ready. The current build intentionally does not publish a guessed LinkedIn URL.
6. Commit the changes to the `main` branch.
7. Check GitHub Pages after deployment.

## Important

The profile area is a clean placeholder because a personal photo was not included with this build. Replace the placeholder with your preferred professional photo when ready.

The engineering project cards intentionally avoid inventing technical specifications. Add verified VAWT/HIRAC images, measurements, and project details from your original files if you want deeper case studies.

The administrative/VA examples are explicitly presented as self-initiated work samples.

## Files

- `index.html` — main portfolio page
- `styles.css` — design system and responsive styles
- `script.js` — navigation, filters, interactions, reveal animations, contact mailto
- `assets/*.csv` — sample administrative datasets
- `assets/resume.pdf` — placeholder file; replace before publishing

## Design

Warm ivory / deep navy / taupe / muted sage.

No gradients, neon, glowing effects, or heavy animation.

Built as plain HTML/CSS/JavaScript so it remains GitHub Pages compatible.
